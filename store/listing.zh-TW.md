# Chrome 商店文案 · 字幕口袋 0.10.0

## 名稱

字幕口袋 · Netflix 英文學習

## 簡短說明

點選 Netflix 英文字幕，翻譯成繁體中文，收藏單字、片語與句子；逐字稿可停靠四邊或半透明浮動。

## 詳細說明（可直接貼入商店）

每一句，都有收穫。字幕口袋讓你在觀看 Netflix 時，查詢英文字幕、收藏新單字，並回到熟悉的對話中複習。

主要功能
• 點選英文字幕或逐字稿中的單字，查看繁體中文詞義。
• 收藏單字、片語與句子，保留原句、影片名稱與時間點。
• 中英逐字稿支援四邊停靠及半透明浮動，點時間可跳轉。
• 複習模式可遮蔽中英文字幕，並在收藏的對話處暫停。
• 在收藏庫搜尋、依類型篩選，匯出 CSV 或 JSON 備份。
• 選用 AI 分析收藏單字的常用度、實用性、標籤與學習優先順序。評分是 AI 估計，並非字頻統計。

翻譯來源與使用條件
單字和片語優先使用隨擴充功能附上的 ECDICT 離線字典；整句優先使用可取得的 Netflix 中文字幕。線上翻譯需要另行設定：Google Cloud Translation 使用你自己的 API 金鑰並依 Google 規則計費；Codex、Antigravity 或 GitHub Copilot 需要另外取得本機橋接程式、安裝 Node.js 22 以上與相應 CLI、登入帳號並啟動服務。第三方額度、費用與模型依帳號及服務規則而定。Chrome 商店安裝包僅包含擴充功能，不包含本機 AI 橋接程式。

資料使用
收藏與設定儲存在目前 Chrome 使用者設定檔。Google 翻譯會收到選取的英文；AI 單字翻譯會附上部分原句，收藏庫 AI 分析會收到單字、中文釋義、部分原句及配對識別碼。翻譯服務不會收到影片名稱或 Netflix 影片網址。完整說明請見隱私權政策。

相容性
需要 Chrome 120 以上、可正常觀看 Netflix 的帳號，以及提供所需字幕的影片。字幕可用性會受影片、語言與 Netflix 播放器變更影響。字幕口袋為獨立開發的學習工具，與 Netflix 無隸屬、合作或背書關係。

## 後台其他欄位

- 主要語言：繁體中文。
- 類別：選擇後台最接近「教育／學習」的選項。
- 網站／支援 URL：填入已公開、可匿名開啟的產品與使用說明頁；尚未設定。
- 隱私權政策 URL：需公開託管 `extension/privacy.html`，不能填本機路徑或需登入的網站。
- 開發者聯絡信箱：由擁有者在後台填入要公開／接收商店通知的信箱。
- 安裝費用與地區：由擁有者依後台選項設定；本文不承諾第三方 AI 免費。
