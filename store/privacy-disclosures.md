# Chrome 商店隱私與權限欄位草稿

依 0.10.0 實作整理。送審時須對照當時後台的分類與定義；不可勾選「完全不處理使用者資料」。

## 單一用途（可貼入）

協助繁體中文使用者透過 Netflix 英文字幕學習英文，提供字幕查詞與翻譯、收藏單字／片語／句子、逐字稿及收藏對話複習；選用的 AI 分析僅用於安排收藏單字的學習順序。

## storage 權限理由（可貼入）

在使用者目前的 Chrome 使用者設定檔中保存學習收藏、字幕、複習與跟讀偏好、翻譯快取、Google 翻譯用量計數，以及使用者自行輸入的 Google API 金鑰和本機 MCP 連線權杖。這些資料用於恢復使用者的學習進度與翻譯設定。

## tts 權限理由（可貼入）

使用者主動按下單字朗讀時，透過 Chrome 系統語音功能播放所選英文，提供正常、慢速與停止操作。只選用本機英文系統語音，不選用遠端或其他擴充功能提供的語音；不需要麥克風存取。

## Netflix 網站存取理由（可貼入）

內容腳本只在 https://www.netflix.com/* 執行，用於取得播放器字幕、顯示中英逐字稿與查詞介面、讀取播放時間、收藏影片資訊、在使用者操作或啟用複習模式時控制跳轉及暫停。腳本在 Netflix 非播放頁等候進入播放頁，以支援其單頁導覽。

## translation.googleapis.com 權限理由（可貼入）

使用者自行設定 Google Cloud API 金鑰並選擇 Google 翻譯後，向固定的 Google Cloud Translation API 傳送需要翻譯的英文及 API 金鑰，取得繁體中文譯文。此主機不提供可執行程式碼。

## 127.0.0.1 選用主機權限理由（可貼入）

只在使用者設定本機 AI 橋接時要求此權限，以 HTTP MCP 與使用者自行啟動的本機服務連線。程式限制網址為 literal 127.0.0.1、/mcp 路徑，使用本機權杖驗證。Chrome 主機權限無法限定連接埠；應用程式使用使用者設定的連接埠。橋接把使用者要求的翻譯／詞彙分析送至所選雲端 AI。

## 遠端程式碼（可貼入）

否。擴充功能使用的 JavaScript、樣式及離線字典隨套件提供。Google 和本機 MCP 回覆僅作為翻譯或結構化詞彙分析資料處理，不作為程式碼執行。本機 Node.js／AI CLI 是使用者另外安裝啟動的選用服務，不由擴充功能下載或執行。

## 資料分類判讀

| 後台分類 | 實際處理 | 填寫依據 |
| --- | --- | --- |
| Website content／網站內容 | 字幕、選取英文、原句及翻譯；線上功能會傳送其中部分內容 | 需揭露 |
| Authentication information／驗證資訊 | Google API 金鑰存本機並送 Google；MCP 權杖存本機並送 127.0.0.1 | 需揭露 |
| Web history／瀏覽記錄 | 收藏會保留 Netflix 影片網址、名稱與時間點；不讀取 Chrome 瀏覽歷史資料庫、不傳送影片網址至翻譯服務 | 依後台對網站網址／瀏覽資料定義揭露；不可宣稱完全不處理網址 |
| User activity／使用者活動 | 本機的播放時間、收藏操作及複習偏好，用於字幕學習 | 對照後台定義揭露本機功能資料；無點擊追蹤或分析上報 |
| 其他敏感分類 | 未實作姓名／信箱表單、付款資料、健康資料、私人訊息或定位蒐集 | 不為不存在的功能勾選；第三方自行登入與付款應另述 |

三項資料用途聲明可依現有程式確認：不出售資料；只用於所列單一學習用途；不使用於信用／貸款決策。政策描述、商店勾選與實際程式必須一致。

## 公開政策

完整政策位於 `extension/privacy.html`。送審前須取得無需登入的 HTTPS 網址，並驗證其內容與套件內政策一致。開發者聯絡管道也須在商店後台設妥。

參考：[Chrome 隱私欄位](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)。
