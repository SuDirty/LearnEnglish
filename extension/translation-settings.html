字典與翻譯設定

單字／片語優先查離線 ECDICT；整句優先用 Netflix 中文字幕。查不到時使用你選擇的翻譯服務。

雲端 AI，透過 MCP 翻譯
  1. 在專案資料夾依 docs/cloud-ai.md 安裝官方 Antigravity／Copilot CLI。
  2. Antigravity：執行 npm run ai:login:antigravity，使用 Google 帳號登入，再執行 npm run mcp:antigravity。
  3. Copilot：使用 Copilot Free 帳號執行 npm run ai:login:copilot，再執行 npm run mcp:copilot。
  4. Codex 沿用原有 npm run mcp。保持所選服務的終端機開啟。
  5. 另開終端機執行 npm run mcp:token，貼到下方並按「儲存並測試連線」。

英文會送到所選 AI 的雲端服務，電腦只執行 MCP 橋接，不下載本機模型。Antigravity 使用 Google 帳號額度；Copilot 請使用 Free 方案。免費額度與可用模型依帳號為準，錯誤時不會切換到付費 API。首次翻譯可能需要數十秒。測試連線只檢查 MCP 與 CLI，實際翻譯才會驗證雲端額度。

金鑰只保存在這個 Chrome 使用者設定檔，不會放入收藏匯出檔。請啟用 Cloud Translation API 與帳單，將金鑰的 API 限制設為 Cloud Translation API。

預設 450,000 字元；設為 0 可停止新的 Google 查詢，已有快取仍可使用。這是此套件的本機限制，不是 Google 帳戶的帳單上限。

用量依 UTC 月份重置，保守計入已送出的嘗試，包含失敗請求；快取、離線字典與中文字幕不計入。Codex 用量另依 Codex 帳號計算，不受此 Google 上限控制。
