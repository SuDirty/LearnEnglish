字典與翻譯設定

單字／片語優先查離線 ECDICT；整句優先用 Netflix 中文字幕。查不到時使用你選擇的翻譯服務。

使用已登入的 Codex 翻譯
  1. 在本專案資料夾開啟終端機，第一次執行 npm install。
  2. 確認已執行 codex login，接著執行 npm run mcp，保持終端機開啟。
  3. 另開終端機執行 npm run mcp:token，把權杖貼到下方。
  4. 按「儲存並測試連線」，允許 Chrome 存取本機服務。

選取的英文會經由本機服務送到 Codex 翻譯，使用現有 Codex 登入與用量額度。服務需保持執行；首次翻譯可能需要數十秒。連線失敗會顯示錯誤，不會自動切換到 Google。App Server 目前屬實驗性功能。

金鑰只保存在這個 Chrome 使用者設定檔，不會放入收藏匯出檔。請啟用 Cloud Translation API 與帳單，將金鑰的 API 限制設為 Cloud Translation API。

預設 450,000 字元；設為 0 可停止新的 Google 查詢，已有快取仍可使用。這是此套件的本機限制，不是 Google 帳戶的帳單上限。

用量依 UTC 月份重置，保守計入已送出的嘗試，包含失敗請求；快取、離線字典與中文字幕不計入。Codex 用量另依 Codex 帳號計算，不受此 Google 上限控制。
