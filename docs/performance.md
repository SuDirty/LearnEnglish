# Codex 翻譯效能

## 2026-09-15 優化

原實作每次翻譯都啟動新的 Codex App Server、初始化、檢查登入，完成後關閉程序。提示詞及輸出格式還要求單字與文法說明，但 MCP 佇列只把譯文傳給擴充功能。未指定推理等級時，會沿用 Codex 設定；本次量測時的全域設定為 `gpt-6-astra`／`high`。

本次修改：

- 同一個後端重用一個已初始化的程序，並行請求共用初始化結果。
- 每句仍建立獨立的暫存對話，不共用對話歷史；完成或失敗後呼叫 `thread/unsubscribe` 釋放訂閱。
- 翻譯只要求 `{ "translation": "…" }`，不再產生介面未使用的說明。
- 保留既有模型，字幕翻譯預設使用 `low` 推理。`CODEX_REASONING_EFFORT` 可覆寫，不修改全域設定。
- 瀏覽器結果輪詢由 1000ms 改為 250ms，減少模型完成後等到下一次查詢的時間。
- 斷線時釋放程序，下一次請求重新連線；不自動重送失敗請求。服務關閉時停止程序，逾時時中斷對應的 turn，包含回覆識別碼延遲到達的情況。

連線初始化、單次推理覆寫與取消對話訂閱的協定依據：[OpenAI Docs：Codex App Server](https://learn.chatgpt.com/docs/app-server)。

## 實測

在同一台電腦、同一 Codex 帳號與模型，以固定順序各執行一次這兩句英文。直接計時 `backend.translate()`，涵蓋程序啟動、初始化、登入檢查、建立對話與模型回覆；未經擴充功能快取或 MCP 輪詢。原版每句重新啟動程序；新版第一句為冷啟動，第二句重用程序。

| 輸入 | 修改前 | 修改後 |
| --- | ---: | ---: |
| I've been learning English for three months. | 10.973 秒 | 6.103 秒 |
| I didn't mean to let you down. | 10.288 秒 | 5.957 秒 |
| 平均 | 10.631 秒 | 6.030 秒 |

這次兩句平均等待縮短約 **43%**。樣本數只有兩句，且同時調整了輸出、推理與程序生命週期，無法把收益歸因到某一項；網路、服務負載、輸入長度與模型狀態仍會影響後續速度。此表未量測瀏覽器輪詢調整的收益，也不代表 Netflix 實片端到端時間。

新版回覆分別為「我已經學英文三個月了。」及「我不是故意要讓你失望的。」；這兩例保留了原句意思，但不是完整翻譯品質評估。

實際驗證新版兩句共用一個程序，且兩次 `thread/unsubscribe` 均回覆 `unsubscribed`。原始量測結果存於已忽略的 `.local/performance-before/results.json` 與 `.local/performance-after.json`。

## 回歸驗證

`npm test` 的 38 項本機測試全部通過，涵蓋 MCP 流程、快取、複習功能，以及新增的程序重用、初始化失敗重試、並行結果隔離、關閉與逾時取消。此次未重新操作 Netflix 真實影片或執行瀏覽器 UI 測試。

## 套用方式

重啟 `npm run mcp` 即可套用後端優化；重新載入既有 Chrome 擴充功能並重新整理 Netflix，套用輪詢間隔調整。若使用的是已打包的 CRX，它仍是先前的產物，需另行更新才能套用瀏覽器端變更；後端優化可先獨立生效。
