# 影子跟讀模式規劃

狀態：第一版已實作；使用方式、已驗證範圍及與提案的差異見 [影子跟讀使用說明](shadowing.md)。下文保留原產品提案，最初依 0.9.2 的逐字稿、播放器橋接與複習功能規劃。

## 1. 核心體驗

在 Netflix 畫面選一句或連續幾句，反覆聽原音、跟著說，完成後進到下一句。練習留在現有逐字稿面板內。

提供兩種練法，分別呈現操作提示：

| 練法 | 一輪流程 | 畫面提示 |
| --- | --- | --- |
| 影子跟讀（預設） | 播放原音，使用者稍晚一點跟著說 → 句尾休息 → 重播 | 跟著原音說 |
| 聽後複誦 | 播放原音 → 暫停並留時間自行說一次 → 重播 | 先聽／換你說 |

第一版以完成練習循環為目標；錄音比較、發音辨識與評分排在後續版本。

## 2. 入口與操作流程

1. 逐字稿工具列新增「跟讀」，以目前播放句作為預選；尚無目前句時提示先選句。
2. 支援單句及連續多列；現有文字選取工具增加「練習這段」。若只選部分單字，練習範圍仍採完整字幕片段，開始前顯示實際涵蓋文字。
3. 顯示範圍、預估長度與「開始練習」。過長片段提示拆段，由使用者決定，不任意依字數切出沒有時間碼的句子。
4. 開始後暫停一般播放、鎖定本次練習範圍，顯示常駐練習列。
5. 預設先示範一次，再進行三輪所選練法。示範不計入三輪。
6. 完成後停在該段結尾，顯示「再練一次／下一句／結束練習」。預設手動換句，可開啟自動下一句。
7. 結束時保留當前影片位置並暫停，恢復原有字幕顯示及本次暫時調整的播放設定；由使用者繼續看劇。

### 面板示意

```text
影子跟讀                         結束練習
第 2 / 5 段 · 第 1 / 3 輪 · 跟著原音說

I've been learning English for three months.
[顯示中文]

上一句    暫停    重來    下一句
練法：影子跟讀 ▾  速度：1.0× ▾  設定
```

窄面板分成多列，保留目前句、播放階段與暫停按鈕。收合面板時保留精簡練習列；切換練習片段時恢復跟隨定位，手動捲動仍可取消跟隨。

## 3. 第一版預設與設定

| 項目 | 提議預設 | 可調整 |
| --- | --- | --- |
| 練法 | 影子跟讀 | 聽後複誦 |
| 示範 | 開啟，播一次 | 開／關 |
| 練習輪數 | 3 輪 | 1–5 輪 |
| 速度 | 1.0× | 0.75×、0.9×、1.0×，須先驗證播放器支援 |
| 影子跟讀休息 | 每輪 1 秒 | 0.5、1、2 秒 |
| 聽後複誦時間 | 該段實際播放長度 + 1 秒 | 1、1.5、2 倍播放長度，再加 1 秒；可提前完成 |
| 字幕 | 英文開、中文收起 | 分別切換；提供臨時顯示答案 |
| 換句 | 手動 | 自動下一句 |
| 練習來源 | 選取的一段或連續數列 | 第一版限當集已載入字幕 |

以上是待試用調整的產品預設，並非學習成效保證。設定記住使用者選擇；重新整理與換集不自動開始練習。

## 4. 時間範圍與字幕規則

- 起訖採英文原始字幕時間。畫面因中文字幕而合併的列，沿用 `parts` 還原英文來源，再取所選片段的開始與結束；顯示列只是選取入口。
- 跨列選取包含中間的影片與靜默區間，預覽明確顯示完整範圍。第一版不自動刪除長停頓。
- 選取後固定本次練習佇列，避免中文軌切換或列表重繪改變正在播放的範圍。
- 起點可向前保留約 100ms、終點向後保留約 150ms，遇相鄰台詞及影片邊界時截斷；實際值需實片驗證，重疊台詞不承諾可獨立切乾淨。
- 只有「播放中收集／時間約略」資料時，第一版提供選句及手動重播，停用自動句尾循環並顯示原因；取得正式字幕時間後可重新開始完整練習。
- 不提供逐字卡拉 OK 高亮：目前只有字幕片段時間，沒有逐字時間。

## 5. 與現有功能的協調

- **複習模式**：跟讀期間暫時接管遮蔽與暫停，避免現有「句首複習暫停」中斷循環。結束後恢復原複習設定，不改寫使用者偏好。
- **查詞與翻譯**：查詞、翻譯、選取文字時先暫停練習；關閉卡片後等待「繼續」，不自動開始下一輪。
- **使用者播放操作**：Netflix 暫停鍵也會暫停練習。任意拖曳進度列或一般逐字稿跳轉會中止目前一輪並進入待命，由使用者選擇重來或結束，不強行拉回。
- **切換字幕**：英文軌改變時停止練習並重新選句；中文軌改變只更新對照，不變更已固定的英文播放範圍。
- **離開分頁或換集**：分頁轉背景時暫停；返回後手動繼續。換集、播放器替換、停用擴充功能時結束練習並清理所有計時與事件。
- **字幕遮蔽**：逐字稿及現有影片字幕翻譯層使用一致規則，沿用複習模式的可存取性處理，避免已隱藏答案出現在按鈕標籤。

## 6. 實作切分

### 播放器控制

擴充 `extension/player-bridge.js` 的命令協定，支援 `seek`、`play`、`pause`、`setRate` 與狀態回報。現有 `seek` 會自動播放，而且允許接近 2 秒的位置誤差；跟讀需能先跳轉、確認到位，再開始播放，並使用更細的位置驗證。

- 命令包含請求 ID、影片路徑與練習 session ID，確認成功才推進階段；過期回覆直接忽略。
- 保留既有逐字稿跳轉語意，新流程以獨立選項控制是否自動播放。
- 速度設定需讀回確認；失敗時保留實際速度並顯示訊息，以實際速度計算複誦時間。
- 句尾以播放器時間判斷，不以固定延遲推算播放完成；緩衝、暫停及 seek 中不增加輪數。
- 查證播放命令造成的事件與使用者操作的區別，避免把自己發出的 seek／pause 誤認為中斷。
- 播放被拒絕、跳轉失敗或逾時時停在可重試狀態，不無限循環。

### 練習引擎

新增 `extension/shadowing.js`，獨立管理狀態、佇列與輪數，狀態包括：

```text
待命 → 定位中 → 示範 → 定位中 → 跟讀播放／聆聽
                                      ↓
                                 休息／自行複誦
                                      ↓
                           尚有輪數：定位中
                           輪數已滿：段落完成

執行中可進入「已暫停」或「錯誤」；結束時清理 session。
```

暫停保存目前階段；複誦倒數保存剩餘時間。按「重來」回到本輪開頭，按「再練一次」才重設整段輪數。

### 畫面與儲存

- `extension/transcript-ui.js`：入口、範圍選取、練習列、狀態顯示；呼叫引擎，不在畫面程式內累積計時邏輯。
- `extension/content.js`：統一跟讀與複習的字幕顯示優先權，查詞時通知引擎暫停。
- `extension/review.js`：保留原複習邏輯，由協調層在跟讀期間停用其暫停判斷。
- `extension/manifest.json`：加入練習引擎載入順序。
- `chrome.storage.local`：儲存 `shadowingSettings`；session、計時器及本集練習佇列留在分頁記憶體。第一版不新增錄音權限。

## 7. 開發順序與驗收

1. **播放器可行性驗證**：登入 Netflix 實片確認句首定位、句尾暫停、變速及還原。先測不同長度句子與連續對話，記錄時間偏差；以大多數正常播放的句尾偏差不超過 250ms 為初步目標，尚未驗證前不承諾精度。
2. **單句循環**：完成兩種練法、輪數、暫停、重來、錯誤復原與字幕控制。
3. **連續練習**：多列佇列、上／下一句、自動換句及設定保存。
4. **整合驗證**：確認查詞、複習、縮放、全螢幕、手動跳轉及換集不互相干擾。

必要測試：

- 三輪練習恰好完成三輪；示範、緩衝、暫停及定位失敗不計輪數。
- 0.75× 播放時依實際速度調整複誦時間，暫停期間倒數停止。
- 重複點擊開始、下一句或重來時，僅最新 session／命令生效。
- 換集及離開分頁後，舊計時器不會再次控制影片。
- 共用中文字幕的合併列、跨列片段及相同文字在不同時間出現時，仍練習正確位置。
- 複習模式已啟用時，跟讀不被句首暫停打斷；結束後恢復原設定。
- 以模擬播放器測狀態轉移，再以 Chrome 擴充功能及登入 Netflix 實片驗證控制精度；模擬測試不能取代實片驗證。

## 8. 後續版本

優先增加「從本集收藏建立練習清單」及本機練習紀錄，再考慮錄音與原音交替回放。若加入語音辨識，辨識文字和實際發音評估要分開設計，不能把文字吻合率當作發音分數；需另做能力、權限與資料處理評估。
