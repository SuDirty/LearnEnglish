# 收藏庫測驗模式規劃

狀態：產品與實作提案，尚未實作。依目前收藏資料、收藏頁與 MCP 架構規劃。

## 1. 核心體驗

從收藏庫挑選要練習的單字、片語或句子，選擇「本機模式／AI 模式」，進行中翻英、英翻中、句子填空。所有題目固定四選一，每題一個標準答案。介面與解析使用繁體中文。

在收藏頁增加「開始測驗」入口，進入獨立測驗頁；既有影片播放中的字幕複習功能保留自己的入口。

## 2. 兩種模式

| 項目 | 本機模式（預設） | AI 模式 |
| --- | --- | --- |
| 出題方式 | 本機規則組合收藏文字、譯文與原句 | 依所選收藏生成題目、干擾選項與解析 |
| 連線需求 | 出題、作答均不發送網路請求 | 產生新題時連接已設定的 AI |
| 正確答案 | 收藏原文或已存譯文 | 以收藏詞義與語境為準，保留來源關聯 |
| 干擾選項 | 所選範圍內其他合適的收藏 | AI 生成意思、用法或文法易混淆的選項 |
| 填空句 | 原句挖空，練習回想原文 | 原句優先，可選新情境例句，練習語境應用 |
| 答後說明 | 顯示收藏對照、完整原句及來源 | 額外解釋正解與其他選項不適合的原因 |
| 主要限制 | 收藏太少或資料不完整時，可出題數較少；無法可靠辨識所有語意歧義 | 需要等待及使用服務額度；生成內容仍可能有歧義 |

「本機」指不使用模型的規則出題。若日後支援在電腦執行的模型，仍歸入 AI 模式。

## 3. 設定與操作流程

收藏庫 → 開始測驗 → 選擇設定 → 檢查／產生題目 → 作答 → 成績與錯題 → 再練習。

| 設定 | 第一版規劃 |
| --- | --- |
| 模式 | 本機／AI，預設本機，之後記住選擇 |
| 收藏範圍 | 預設目前篩選結果（類型、標籤、搜尋），可切換全部收藏；顯示筆數 |
| 題型 | 中翻英／英翻中／句子填空，可複選，預設全選 |
| 題數 | 5／10／20 題，預設 10 題 |
| 抽題方式 | 隨機／錯題優先，預設隨機 |
| AI 填空素材 | 收藏原句／新情境例句，預設收藏原句 |
| 計時 | 預設不限時；只記錄作答時間 |

- 開始時固定本次收藏快照；生成完成後固定題目與選項順序。
- 同一筆收藏一回合最多當一道題的目標，避免翻譯題先透露後續填空題答案；仍可在不同回合練習其他題型。
- 多題型盡量平均分配，再按合格題數調整。預覽顯示實際分配；缺少某類題目須明確說明。
- 題數不足時顯示「設定 10 題，目前可出 6 題」及原因，提供「開始 6 題／調整設定」。不得重複湊題、默默擴大收藏範圍或自動切換模式。
- 沒有合格題目時停在設定頁，提示缺少的是收藏數、譯文、原句或可用選項。

## 4. 三種題型

### 中翻英

- 題幹顯示中文意思，四個選項為英文單字、片語或句子，匹配收藏類型。
- 單字有多種意思時依收藏語境限定；本機無法可靠拆分多義譯文時保留完整收藏釋義，不任意取第一義。
- 若顯示英文原句協助判斷，必須遮住目標文字的全部出現位置；無法安全遮蔽時不顯示。
- 答後呈現收藏英文、中文及完整原句。

### 英翻中

- 題幹顯示收藏英文，四個選項為繁體中文。
- 單字與片語可附英文原句限定意思；答前不顯示中文對照。
- AI 干擾選項優先使用相近但不符合本句的意思，避免出現兩個同樣正確的譯法。

### 句子填空

- 題幹為英文句子，挖掉一段文字，四個選項為英文單字或片語。
- 單字／片語收藏：從 `context` 找到收藏文字後挖空；第一版本機只接受忽略大小寫的完整詞邊界匹配，不猜詞形變化。
- 句子／段落收藏：從 `text` 中找出與範圍內其他單字／片語收藏精確匹配的片段，作為挖空目標；本機第一版不隨機挖任意字。過長段落無法安全拆句時跳過。
- 同一目標在句中重複出現時，本機第一版跳過該填空題，避免另一處洩漏答案或變成多空題。
- 本機題幹明示「依收藏原句，選出原本的文字」，測量原文回想；不把規則抽出的其他選項宣稱為文法上一定錯誤。
- AI 可選擇句中的實質單字／片語；新情境例句必須使用收藏的目標意思，並標示「AI 例句」，不可偽裝成影片原文。
- 挖空使用固定寬度，不透露答案長度。答後還原完整句子；只有現成或 AI 生成的對應中文才顯示句譯。

### 題目示例（示意資料）

收藏：`postpone`／「延後」；原句：`We had to postpone the meeting until Friday.`

| 題型 | 題幹 | 選項示例 |
| --- | --- | --- |
| 中翻英 | 「延後」的英文是？ | postpone／confirm／cancel／attend |
| 英翻中 | postpone 在此原句中的意思是？ | 延後／確認／取消／參加 |
| 句子填空 | We had to ____ the meeting until Friday. | postpone／confirm／cancel／attend |

這組填空選項可能有其他符合文法的答案，所以只適合標示為本機「回想原文」題。AI 語境題需要更充分的上下文與不同的選項，不能直接沿用並宣稱唯一合理答案。本機選項也須實際存在於本次收藏範圍，示例不代表內建題庫。

## 5. 出題品質與資料不足

### 共通檢查

1. 題目必須連結本次範圍內仍有效的收藏識別碼；英文、中文等必要欄位不可空白。
2. 四個選項經空白、大小寫及基本標點正規化後不可重複；答案 ID 必須且只能指向一個選項。
3. 相同英文與相同語境、相同譯文的收藏在出題時去重；不改動實際收藏。
4. 避免選項類型與長度懸殊、正解固定在同一位置，以及題幹、提示或可存取標籤洩漏答案。
5. 標準答案位置隨機並盡量均衡。儲存作答時使用選項 ID，不用打亂前的陣列索引。

### 本機篩選

- 翻譯題優先選同收藏類型、相近長度的干擾選項；可靠的本機詞性資料存在時才加上詞性限制，不把 AI 標籤當詞性。
- 排除與正解相同的原文、相同譯文，以及可解析釋義有明顯重疊的候選項；格式無法可靠解析時採保守策略跳過。
- 規則無法保證排除所有同義詞與字幕意譯造成的歧義，因此提供「題目有疑義」。
- 每題必須找到三個合適干擾項；只達到四筆收藏並不代表一定能出題。不足時跳過，讓使用者自行擴大範圍。

### AI 產生與檢查

- 沿用目前支援的 Codex／Antigravity／GitHub Copilot MCP 設定，新增出題能力；Google Cloud Translation 不作為出題服務。
- 以小批次產生（初始建議每批 5 題），顯示進度，可取消後續批次。只提供合格題目供開始測驗。
- 提示詞要求答案符合收藏語境、干擾項不可同義、逐項解析，以及來源 ID；模型自查仍不等於能保證語意唯一。
- 本機驗證回傳格式、ID、答案、選項重複、挖空位置與來源一致性。失敗題最多補產一次，仍不合格就跳過並顯示實際題數。
- 連線失敗、工具不支援或逾時時保留已完成批次，可重試、以已完成題數開始，或由使用者選擇重新以本機出題。
- 傳送內容限所選收藏的識別碼、英文、中文與必要原句；設定頁說明使用目前 AI 服務及其額度。
- 第一版預設待整份合格試卷準備好才開始，作答中不依賴 AI 連線。收藏文字當資料處理，不當作模型指令；回傳文字以純文字呈現。

## 6. 作答與成績

- 每頁一題：模式、題型、第幾題／總題數、題幹、四個選項、「確認答案」。選項可在確認前修改。
- 確認後鎖定首次答案，標示正誤並揭曉解析；由使用者按「下一題」。支援鍵盤 1–4 選答案、Enter 確認／繼續，避免長按連續提交。
- 提供「不知道」，視為本題未答對並揭曉；中途結束則標示未完成，其餘未作答題不記為錯題。
- 「題目有疑義」將本題排除計分、停止用它更新熟悉度，並從後續抽題移除；不自動修改收藏內容。
- 結果顯示：答對／已完成有效題數、正確率、各題型表現、答錯與不知道的收藏。有效題數為零時顯示「尚無可計分題目」。
- 完成後提供「重練錯題／再測一次／返回收藏庫」。重練重新建立回合並打亂選項，不覆寫原成績。
- 「錯題優先」優先抽最近答錯或不知道的收藏，再補其他合格收藏；同一筆收藏按題型分別記錄表現，不與現有 AI 學習優先評分混用。

## 7. 資料與程式切分

沿用 `chrome.storage.local`，新增獨立測驗資料，不更動既有收藏的語意。

| 資料 | 主要欄位／用途 |
| --- | --- |
| `quizSettings` | 模式、範圍設定、題型、題數、抽題方式、AI 例句選項 |
| 題目 | `id`、`entryId`、相關來源 ID、`sourceFingerprint`、`type`、`mode`、題幹、選項 ID 與文字、答案 ID、解析、來源快照、生成版本 |
| `quizSession` | 回合 ID、題目快照與順序、目前題號、首次作答、時間、完成／中止狀態；第一版一個可續作回合 |
| `quizHistory` | 回合摘要與錯題；建議先保留最近 100 回合，可清除 |
| `quizProgress` | 收藏 ID × 題型：已答次數、答對次數、最近結果、最近作答時間 |
| `quizCache` | 通過檢查的 AI 題目；依來源內容、題型、模式設定、模型與出題版本區分，設容量上限並淘汰最久未用題目 |

- 來源指紋涵蓋題目使用的目標與干擾項收藏內容；任何依賴收藏修改或刪除，相關快取不得用於新回合。
- 已開始回合保留當時快照供續作與回顧。若來源已刪除或更新，顯示提示，不將舊題結果寫入目前收藏的進度，也不復原已刪收藏。
- 用回合 ID＋題目 ID 保證重複點擊、重新整理不會重複計分；由 background 統一寫入進度，防止多分頁覆寫。第二分頁提供接續現有回合。
- 現有收藏 CSV／JSON 匯出維持原有範圍；測驗歷史匯出可列為後續功能。

建議檔案：

- `extension/library.html`、`extension/library.js`：測驗入口與目前篩選快照。
- `extension/quiz.html`、`extension/quiz-ui.js`：設定、生成進度、作答與結果。
- `extension/quiz.js`：候選題篩選、本機出題、題目驗證、抽題與計分。
- `extension/background.js`：測驗儲存、工作調度與 AI 請求。
- `extension/mcp.js`、`bridge/`、`providers/`：新增 `generate_quiz` 能力與各供應商結構化回傳，沿用工作輪詢機制。

## 8. 實作順序與驗收

### 第一階段：完整本機流程

完成收藏入口、範圍設定、三種四選一題型、答後對照、成績、錯題重練與重新整理續作。三種題型共同遵守資料不足規則。

驗收重點：完全斷網可用；相同選項與重複答案被排除；多義、缺原句、大小寫、詞邊界、片語與重複詞處理正確；少量收藏不湊假題；隱藏答案不洩漏；重複提交與多分頁不重複計分。

### 第二階段：AI 模式

接上三個既有 MCP 供應商的出題能力、生成進度、解析、AI 例句、快取、取消與失敗復原。

驗收重點：錯誤 ID／重複選項／答案缺失會拒收；取消後不追加本回合題目；部分成功與逾時可恢復；收藏更新後快取失效；人工抽查多義字、近義詞、句子意譯及 AI 解析的合理性。

### 後續擴充

依使用情況再加入難度調整、到期複習排程、趨勢圖與測驗歷史匯出。第一版先確保兩種模式與三種題型都有清楚、可靠的完成流程。
