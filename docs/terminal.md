# 終端機啟動與翻譯紀錄

## 選擇模型

先在原服務終端機按 Ctrl+C，再從專案根目錄啟動：

```sh
cd /Users/bob/Documents/workspaces/LearnEnglish
npm run mcp
```

互動終端機會先檢查 Codex 連線與登入，再從帳號取得可用文字模型。輸入清單編號或模型名稱；按 Enter 使用建議選項。若帳號提供 `gpt-5.6-luna`，會把它列為預設；否則使用清單建議的模型或第一個可用模型。

模型清單是即時取得的，編號可能隨帳號可用模型而變動。選擇僅用於這次啟動，不修改全域 Codex 設定。重新啟動後可以再選。

推理等級預設為 `low`；所選模型不支援時改用它提供的預設等級。也可以用 `CODEX_REASONING_EFFORT` 明確指定，無效的組合會在啟動時顯示錯誤。

模型能力清單依據：[OpenAI Docs：Codex App Server models](https://learn.chatgpt.com/docs/app-server#models)。

## 終端機會顯示什麼

- 啟動：連線狀態、所選模型、推理等級、登入方式、服務網址、佇列容量及權杖檔案位置。
- 收到請求：工作編號、文字長度與原文摘要。
- 開始翻譯：排隊時間、目前執行及等待筆數。
- 等待超過 5 秒：每 5 秒顯示一次等待耗時；不顯示無法估計的完成百分比。
- 完成：翻譯耗時、含排隊的總耗時，以及譯文摘要。
- 失敗：錯誤訊息與耗時；HTTP 認證或來源被拒也會顯示狀態。
- 累計：這次服務啟動後的完成／失敗筆數及成功翻譯平均耗時。

範例輸出（時間與工作編號僅示意）：

```text
[12:47:28] #205fc497 收到翻譯 · 30 字元 · 執行 0／排隊 1
[12:47:28] #205fc497 原文：I didn't mean to let you down.
[12:47:28] #205fc497 開始翻譯 · 排隊 0.0 秒 · 執行 1／排隊 0
[12:47:29] 實際模型：gpt-5.6-luna／推理 low
[12:47:33] #205fc497 翻譯中 · 已等待 5.0 秒 · 執行 1／排隊 0
[12:47:35] #205fc497 完成 · 翻譯 6.3 秒 · 總耗時 6.3 秒 · 執行 0／排隊 0
[12:47:35] #205fc497 譯文：我不是故意要讓你失望的。
[12:47:35] 本次累計：完成 1 筆／失敗 0 筆／平均翻譯 6.3 秒
```

終端機不逐筆列出高頻率的結果輪詢。擴充功能的快取、離線字典或 Netflix 中文字幕命中時，不會送到此服務，因此不會出現在終端機統計中。切換模型後若要比較譯文，請查未翻譯過的文字，或先清除擴充功能設定頁的 Codex 快取。

原文及譯文摘要最多顯示前 160 字，控制字元會移除；Bearer 權杖及常見金鑰格式會遮蔽。紀錄只寫到終端機，不額外保存成檔案。若不想在終端機顯示翻譯文字，可使用：

```sh
MCP_LOG_TEXT=0 npm run mcp
```

這也會隱藏可能包含原文的模型錯誤內容，保留工作狀態與耗時；詳細錯誤仍可在擴充功能查看。

## 直接指定模型及自動化啟動

指定 `CODEX_MODEL` 會略過選單：

```sh
CODEX_MODEL=gpt-5.6-luna CODEX_REASONING_EFFORT=low npm run mcp
```

沒有互動輸入／輸出，或指定 `--no-prompt` 時，不會等待選單。若沒有 `CODEX_MODEL`，沿用 Codex 的模型設定，首筆翻譯時才顯示實際解析出的模型：

```sh
npm run mcp -- --no-prompt
npm run mcp -- --help
```

Ctrl+C 會停止服務並釋放 Codex 程序。若連接埠已被使用，啟動會顯示先停止原服務的提示；不會擅自停止另一個服務。
