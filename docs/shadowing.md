# 影子跟讀

## 開始練習

1. 重新載入 Chrome 擴充功能，再重新整理 Netflix。
2. 等待逐字稿出現後，點工具列「跟讀」練習目前句；也可直接點任一列的「跟讀」。
3. 想練習一段對話時，拖曳選取跨列英文，再點「練習這段」。預覽會顯示完整字幕片段與長度；只選部分單字仍播放其所屬的完整片段。
4. 在練習列直接選「語速」和「每句練幾次」，再按「開始練習」。按「設定」可在獨立視窗選擇練法、休息時間、示範與自動換句，設定會自動記住。

| 練法 | 一輪流程 |
| --- | --- |
| 影子跟讀 | 原音播放時跟著說 → 句尾休息 → 重播 |
| 聽後複誦 | 聽原音 → 原音暫停，換你說 → 重播 |

預設示範一次、練習三輪；示範不計輪數。速度可選 0.75×、0.9×、1.0×；影子跟讀休息可選 0.5、1、2 秒。複誦時間依片段長度、實際播放速度與所選倍數計算，再加 1 秒，也能按「說完了」提前結束本輪。

## 練習中

- 「暫停／繼續」保留目前階段，複誦倒數在暫停時不會消耗。
- 「重來」重播本輪；完成後的「再練一次」會重設整段輪數。
- 「上一句／下一句」切換本次清單中的片段。清單包含所選片段及之後的本集字幕；預設每段完成後等待手動操作，開始前可開啟「自動下一句」。第一段跨列選取會保留為一整段。
- 英文預設顯示、中文預設隱藏，練習中可以分別切換；逐字稿和影片字幕翻譯層一起套用。沒有對應中文字幕時顯示提示，不自動呼叫翻譯服務。
- 練習中也能修改設定：變更語速、次數或練法後會暫停，按「繼續」從本輪開頭套用新設定，不必結束或重新選句。減少練習次數時，目前輪數會限制在新次數內。字幕切換不會中斷練習。
- 「設定」會暫停正在進行的練習；關閉視窗後仍等待你按「繼續」。設定視窗只顯示所選練法需要的時間選項；複誦時間以「一般／多留一點時間／慢慢說」選擇，並顯示這段預計留幾秒。Esc 也能關閉設定視窗。
- 查詞、翻譯或拖曳選取文字會暫停練習；關閉卡片後按「繼續」。手動拖曳影片進度後按「繼續」，會從本輪開頭重播。
- 收合逐字稿後，精簡列仍提供暫停／繼續和結束按鈕。
- 切到背景分頁會暫停，返回後手動繼續。換集、播放器替換、切換英文軌或停用擴充功能會結束本次練習。
- 結束時保留播放位置並暫停，恢復原播放速度及複習設定。若播放器未確認還原，會提示檢查播放狀態與速度。

## 字幕與相容性

有正式字幕軌時，練習使用英文片段的起訖時間；切換中文字幕不會改動已固定的練習清單。第一版直接使用字幕時間，不額外增加句首／句尾留白，也沒有逐字時間高亮。

若只取得「播放中收集／時間約略」字幕，提供手動跟讀與重播，**不自動在句尾停止或循環**。取得正式字幕軌後，可重新選句開始完整練習。

播放器跳轉、播放被拒絕或回應逾時時，練習停在可重試狀態。Netflix 內部 API 與影片時間碼仍可能因播放器版本或片源而異；目前驗證包含真實 Chromium 擴充功能、可播放及跳轉的測試媒體，以及模擬 Netflix 控制 API，尚未驗證登入 Netflix 實片，不能據此保證實片句尾精度。

第一版沒有錄音、發音辨識或評分，也不新增麥克風權限。

## 開發驗證

```sh
node --test test/shadowing.test.mjs
npm run test:shadowing:browser
npm run test:layout
node scripts/browser-smoke.mjs
```

瀏覽器測試可透過 `PLAYWRIGHT_MODULE` 指定 Playwright 模組，`CHROME_BIN` 指定可載入擴充功能的 Chromium。測試使用暫存瀏覽器設定檔與本機生成的無聲音訊，不操作使用者的 Netflix 帳號。

播放引擎位於 `extension/shadowing.js`，介面與跨執行環境通訊位於 `extension/shadowing-ui.js`；`extension/player-bridge.js` 負責頁面播放器控制、精確定位確認與過期指令檢查。
