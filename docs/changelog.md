# 版本紀錄

## v0.9.2：修正找不到 Codex 執行檔

修正「spawn codex ENOENT」：服務會依序使用 `CODEX_BIN`、終端機 PATH，以及 macOS 的 Applications 中 Codex／ChatGPT app 內建執行檔。亦會檢查使用者的 Applications 與 Homebrew 常用路徑。明確設定但無效的 `CODEX_BIN` 會顯示修正提示，不會改用其他版本。

**更新後需重啟本機服務：**在執行 `npm run mcp` 的終端機按 Ctrl+C，再執行 `npm run mcp`。不用重建權杖或移除擴充功能。

若暫時使用舊版程式，這台 Mac 可用以下方式指定已確認存在的執行檔：

```sh
CODEX_BIN="/Applications/ChatGPT.app/Contents/Resources/codex" npm run mcp
```

其他電腦請換成實際路徑。此問題修正位於 `providers/codex/`；若使用解壓縮版本，也要更新橋接程式，不能只換 `extension`。

## v0.9.1 版本說明

此版包含 v0.9.0 的複習模式與版面功能，以及完整的 MCP／Codex 翻譯整合。修正 Chromium 中 MCP 請求的 `fetch` 綁定問題，並包含窄面板標題換行與翻譯卡片尺寸修正。

目前原始碼版本為 **0.9.2**，版本以 `extension/manifest.json` 與根目錄 `package.json` 為準。`releases/` 保存既有 ZIP；本次整理未產生新的發行套件。

**更新既有安裝：**將新版本 `extension` 的內容覆蓋到 Chrome 原本載入的資料夾，接著在 `chrome://extensions` 按「重新載入」並重新整理 Netflix。若原本就載入這個開發資料夾，直接重新載入即可。保留原本套件安裝與路徑，避免另外建立一個不同的擴充功能；不需移除舊套件。

## v0.9.0 複習模式

在逐字稿上方點 **設定與資訊**，再展開 **複習模式**，勾選「啟用複習模式」。預設關閉；開啟後預設遮蔽中文，收藏種類預選全部。

- **遮蔽中文字幕／遮蔽該句英文字幕**：兩者獨立選取，可同時遮蔽。會遮蔽逐字稿及影片上目前顯示的對應語言字幕；僅處理本片有符合收藏條件的句子。
- **依收藏種類**：單字、片語、句子／段落可複選，符合任一類型就納入。全部取消時不遮蔽、不自動暫停，並提示選擇類型。
- **播放到目標對話時暫停**：進入符合條件的句子時暫停。手動按播放後可繼續，不會在同一句反覆暫停；倒帶或跳轉重播時會重新觸發。與既有「查詢時暫停」分開設定，也能單獨啟用而不遮蔽字幕。沿用播放器約 250ms 的字幕輪詢，實際停止可能比句首稍晚；播放中收集模式的時間仍為估計值。
- **顯示答案／重新遮蔽**：在目標句旁切換，影片上的遮蔽也會同步更新。顯示答案不會自動播放。跳轉、換集或調整複習設定後重新遮蔽。
- **收藏比對**：使用影片網址、收藏原句和時間定位，避免同字出現在別句就誤遮。舊收藏仍可使用；跨句段落會依保存的完整原句比對連續字幕。新版收藏保留精確起迄時間；舊資料缺失、不同字幕軌的譯寫或切句差異可能無法比對。
- **設定保留**：複習設定保存在本機，換集後仍保留，但只比對新影片的收藏。新增或刪除收藏會即時更新。

更新方式：在 `chrome://extensions` 重新載入原有擴充功能，再重新整理 Netflix。若原本載入另一個資料夾，將這版 `extension` 的內容覆蓋到原資料夾後再重新載入；不需移除既有擴充功能。
