# 使用與資料

## 使用

- **精簡工具列**：上方保留拖曳、收合與整句翻譯；字幕來源、載入狀態、字幕軌選擇、複習模式、浮動透明度及操作說明移到「設定與資訊」視窗。按右上角 × 或 Esc 關閉。
- **調整單字區**：查單字後，拖曳單字卡與逐字稿之間的分隔線調整大小；上下排列時調高度，並排時調寬度。分隔線可用 Tab 聚焦，再用方向鍵調整，Shift 加快；尺寸會記住，視窗縮小時自動保留字幕閱讀空間。
- **目前句子置中**：跟隨播放時，目前句子會在可見的字幕列表內置中；開啟、關閉或縮放單字區會重新計算。手動捲動後保持原本的取消跟隨行為，按「恢復跟隨」才重新置中。靠近列表開頭或結尾時，以可捲動範圍為限。
- **拖曳停靠**：按住逐字稿標題左上方的「⠿」拖動，離開原位置即切成浮動；拖到視窗上、下、左、右邊緣 36px 內會顯示停靠預覽，放開即靠邊。版面不再使用下拉選單。聚焦把手後可用方向鍵移動，Shift＋方向鍵直接停靠，Esc 取消拖曳。固定在四邊時，播放器使用剩餘空間；浮動時影片維持原尺寸。
- **自由縮放**：左右停靠時拖內側邊緣調寬度，上下停靠時拖內側邊緣調高度；浮動時可拖四邊或四角。縮到太小後放開會自動收合，留下 44px 展開列，不會完全消失；再次展開恢復這次縮放前的可用尺寸。收合門檻：左右寬度低於 180px、上下高度低於 140px、浮動寬度低於 220px 或高度低於 200px。縮放邊緣也可聚焦後用方向鍵操作。
- **半透明浮動**：「重設浮動位置」回到右上方；「背景不透明度」可調整 25%～95%，文字本身保持清楚。位置、尺寸及不透明度會存於本機，重新整理或換集仍保留，視窗縮小時會限制在可見範圍。
- **全螢幕**：分區模式下，播放器的全螢幕按鈕會讓整個工作區進入全螢幕，以保留字幕學習區。這個做法不搬移或重建正在播放的影片元素。
- **逐字稿**：點英文單字可查獨立詞義，不會觸發時間跳轉；點時間按鈕或句子周圍空白處會跳到該句並開始播放，點旁邊「翻譯」查整句並可收藏。
- **同時間字幕合併**：同一字幕軌、同一起始時間（毫秒精度）的文字片段會整合為一筆，保留來源順序與換行，完全重複的片段只保留一次。結束時間採用各片段中最晚的時間，跳轉、播放高亮、翻譯與收藏都使用合併後的句子。中英文軌各自合併後再做時間對照；不會因畫面時間標籤都顯示同一秒，就把實際起始時間不同的台詞合併。
- **中英切句不同**：若連續的英文片段（間隔不超過 1 秒）都對應到同一組中文字幕片段，會在列表中整合為一筆，中文只顯示一次。例如 10:23 的「I can't believe you spent my wedding fund」和 10:25 的「on the beach house!」，共用同一個中文字幕區間時，會合成從 10:23 開始的一筆。跳轉、收藏與高亮都使用合併後的完整句子。比對依據是中文字幕的來源時間片段，不是中文字串；不同時間的相同中文、沒有對應字幕或中間夾有其他字幕時，不會因此合併。英文原始軌保留不動，切換中文軌會重新計算列表。
- **優先使用中文字幕**：播放器就緒後，套件先記住目前字幕軌（包含關閉字幕），按需要暫時切換英文及中文以觸發載入，優先繁體中文，結束或失敗後嘗試還原原設定。若你途中自行換字幕，會停止自動切換並保留你的新選擇。載入後，逐字稿會顯示時間對齊的中文字幕；整句翻譯直接使用字幕，不呼叫外部翻譯服務。有多個中文字幕軌時預設優先繁體，也可從列表上方選單手動選擇。沒有中文字幕或找不到時間對應時才改用所選翻譯服務（Google 或 Codex）。
- **單字與中文對照**：單字詞義優先由離線 ECDICT 查詢，查不到才使用所選翻譯服務；卡片會另外列出對應的 Netflix 中文整句，作為上下文參考。中英字幕可能意譯、合併或拆句，不能把整句中文字幕當成單字的獨立翻譯。
- **跟隨播放**：目前句子會高亮，列表自動捲到它的位置。手動滾輪、觸控、拖曳捲軸或鍵盤捲動會取消自動跟隨，高亮仍繼續更新；按「恢復跟隨」立即回到目前句子並繼續跟隨。右上角可收合／展開列表。
- **字幕來源**：讀到 Netflix 已載入的 TTML／WebVTT 字幕軌或瀏覽器文字軌時，列表會顯示整份字幕及原始時間。若讀不到，改為收集播過的字幕，標示「播放中收集／時間約略」（約 250ms 輪詢，若中途加入可能偏差更大）。自動取得失敗時，面板會顯示原因與「重試載入字幕」；多個可用字幕軌會出現選單。不同影片的列表會分開，重新整理後重新讀取，不會自動存進收藏。
- **查單字**：點字幕裡的英文字，面板內會出現繁體中文翻譯。
- **查整句**：點逐字稿列表上方「翻譯整句 ↗」，或翻譯卡片內的「翻譯整句」。也可用逐字稿每一列的「翻譯」選取該句；共用中文字幕的連續英文片段會合併；也可拖曳選取多列。
- **選片語／段落**：在逐字稿從英文單字拖曳到結尾單字，以完整單字為邊界選取，可跨行或跨列。選取後，下方出現預覽及「翻譯並準備收藏」按鈕，點擊才查翻譯；拖曳時會取消自動跟隨，避免字幕移動，也不會誤觸跳轉。只收集所選英文，不包含時間、中文或操作按鈕。可按「取消選取」或 Esc 清除選取，按「恢復跟隨」回到播放位置。
- **收藏整句**：每列右邊的 ☆ 開啟整句翻譯與收藏卡片，確認後再儲存。
- **收藏類型**：卡片可選「單字／片語／句子・段落」。拖曳選取時，單一字預設單字、多字預設片語，完整選取原句則預設句子；可以手動調整。單字和片語查詢只翻譯所選文字，完整中文字幕另外保留供上下文參考。把部分文字改分類為句子，也不會直接套用整句中文。多列完整選取使用時間範圍尋找中文字幕，覆蓋不足則使用所選翻譯服務。
- **收藏**：翻譯完成後按「＋ 收藏」。會存下英文、中文、原句、影片名稱、影片網址、時間位置、翻譯來源、對應中文字幕和收藏日期。同一影片裡相同原句的同一個單字不會重複收藏；將原本機器翻譯的句子重新以 Netflix 中文字幕收藏，會更新原收藏譯文。
- **查看 / 搜尋**：點工具列圖示 →「打開我的收藏」，可依單字、片語、句子篩選，搜尋英文、中文、原句和影片名稱。
- **備份**：收藏頁可匯出所有收藏為 CSV（Excel 可開啟）或 JSON。JSON 目前供外部備份使用，尚無匯入介面。
- **播放**：預設查詢時暫停。關閉卡片後手動按 Netflix 播放鍵繼續，避免還沒讀完就繼續播放。可從工具列設定關閉暫停功能。
- **停用**：從工具列關閉「啟用字幕翻譯」會恢復原本字幕。

影片連結會開啟原影片；收藏中的時間供手動跳轉參考，不保證 Netflix 自動跳到該秒數。影片名稱會優先讀取播放器標題，取不到時使用網頁標題。

## 翻譯與資料

整句優先使用同影片、所選中文軌的時間對照，不會送出外部查詢。比對會合併同一英文字幕時間內有足夠重疊的中文片段；覆蓋不足時不硬配相鄰句，改用翻譯服務。字幕分段和時間差仍可能造成不完全對應。

單字／片語先查套件內建的 [ECDICT](https://github.com/skywind3000/ECDICT)，含 768,741 筆詞條，中文使用 [OpenCC](https://github.com/BYVoid/OpenCC) 轉成繁體。離線可用、不需帳號、沒有查詢額度，詞條按首字母分檔載入。可顯示詞性、詞義及原資料提供的音標；支援大小寫與部分變化形。字典是一般詞義，並不依劇情自動選義，可能有過時詞義；可按「改用所選翻譯服務」比較。

字典查不到的單字／片語、沒有中文字幕對應的句子，使用所選的線上服務。選擇 Google 時，使用 [Google Cloud Translation Basic v2](https://docs.cloud.google.com/translate/docs/reference/rest/v2/translate) NMT（英文 → 繁體中文）。需要自己的 Google Cloud API 金鑰；尚未設定時會提示設定，離線字典和 Netflix 中文字幕仍可用。不再呼叫 MyMemory，舊收藏保留；重新查詢並收藏可更新舊的機器翻譯，Netflix 中文字幕優先保留。

### 設定 Google 翻譯

1. 建立／選擇 Google Cloud 專案，啟用帳單及 [Cloud Translation API](https://console.cloud.google.com/apis/library/translate.googleapis.com)。
2. 在 [憑證頁](https://console.cloud.google.com/apis/credentials) 建立 API 金鑰，將 API 限制設為 **Cloud Translation API**。
3. 點 Chrome 工具列「字幕口袋」→「字典／翻譯設定」，或點翻譯卡片裡的同名按鈕。
4. 貼上金鑰並儲存。欄位不會回填金鑰；留白儲存會保留舊值，也可按「移除金鑰」。不需要把金鑰貼到對話或程式碼裡。
5. 本機每月上限預設 **450,000 字元**，可自行調整；設為 0 停止新的 Google 查詢。離線字典、中文字幕及已存快取仍可使用。

依 [Google 官方定價](https://cloud.google.com/products/translate/pricing)（2026-09-15 查核），Basic／Advanced 的標準 NMT 每月前 500,000 輸入字元以 US$10 抵免涵蓋，後續一般費率為每百萬字元 US$20；同帳戶適用的服務用量會影響抵免，請以當期官方定價與帳單為準。套件上限只統計此 Chrome 設定檔，**不是 Google 帳戶的帳單上限**，不能保證零費用。

設定頁顯示本機 UTC 月份的字元數、請求數與快取筆數；跨月重置。保守計入已嘗試送出的請求（包含失敗／逾時），按 Unicode code point 計數，含空白；快取命中不計費用量。Google 翻譯快取保存到本機，最多 300 筆，重啟 Chrome 仍可用，可手動清除。每次最多查詢 2,000 字元。

Google 只收到所選文字與語言參數，不另外傳送原句上下文、影片名稱或網址；若所選內容就是原句，該句會送出。一般 NMT 不會以額外上下文替單字選義，卡片另外保留中英原句供比對。連線也會帶一般網路資訊，例如 IP。離線字典和中文字幕不會送去 Google。

收藏、金鑰、快取及設定使用 `chrome.storage.local`，不會同步到其他電腦。金鑰保存在本機，並非加密保管庫；收藏匯出只含收藏資料，不含金鑰。移除擴充功能或清除其資料會刪除收藏，請先匯出備份。

基本權限為 `storage`、Netflix 內容腳本和 Google Translation API 存取；選用 Codex 時額外請求 `http://127.0.0.1/*` 本機連線權限。沒有廣泛網站、瀏覽歷史、Cookie 或帳號存取權限。程式不下載影片、不讀取 DRM 內容；讀取播放器文字與 Netflix 已載入的文字字幕回應。逐字稿留在分頁記憶體，不會自動整份送去翻譯。

字典授權收錄於 `extension/licenses/ECDICT.txt`，OpenCC 建置轉換工具授權於 `extension/licenses/OpenCC.txt`。來源雜湊與筆數位於 `extension/dictionary/info.json`。目前已附建好的字典；此工作區未附字典重建腳本，一般使用者無需重建。

## 相容性與疑難排解

- 這一版以 Netflix 網頁播放器的 `.player-timedtext-text-container` 文字字幕為讀取入口，在字幕位置呈現可點選的文字層。Netflix 改版可能需要調整這個入口。
- 四邊停靠模式會調整 `.watch-video` 播放器容器的可用寬度，找不到時使用包含影片、字幕和控制列的共同容器；原本的影片節點保留不動。播放器 DOM／CSS 改版或既有全螢幕狀態可能影響版面，更新套件後請重新整理 Netflix。
- 逐字稿擷取支援頁面 XHR 文字／ArrayBuffer／Blob 及 fetch 的 XML／VTT／文字回應。播放器若透過 Worker、其他格式或已快取而未再次請求的方式取得字幕，可能只能使用已播句子的收集模式。解析上限為每軌 4MB、15,000 句；複雜 TTML 排序時間容器及非文字字幕不支援。
- 跳轉優先使用 Netflix 頁面播放器 API，否則嘗試 HTML video；會檢查實際時間是否到位，失敗時顯示訊息。Netflix 內部 API 改版後可能需調整，含廣告片源的時間軸相容性尚未驗證。
- 只處理 `www.netflix.com/watch/...` 的英文文字字幕。Netflix App、圖片式字幕、畫中畫視窗不在此版本範圍。
- 沒有翻譯層：確認已播放影片並開啟英文字幕，重新整理 Netflix；更新擴充功能後也要重新整理。
- 自動載入會等待播放器就緒最多 20 秒，每個字幕軌等待資料最多 5 秒；只切換字幕，不會改音軌、播放位置或播放狀態。字幕可能短暫顯示成其他語言，還原後可從逐字稿查詞，即使原本設定為關閉字幕。
- 自動載入依賴 Netflix 播放器提供的字幕列舉、讀取及切換方法，支援 TimedText／Text 兩組命名；無法讀取原設定時不會貿然切換。播放器改版、無該語言字幕或字幕回應未經可讀取管道時可能無法取得資料，可按「重試載入字幕」。若還原本身失敗，會明確顯示需在 Netflix 字幕選單確認的訊息。換集會停止舊工作，避免把上一集的字幕軌套到新影片。
- 本機測試使用模擬播放器和實際載入的 Chrome MV3 擴充功能；**尚未在登入的 Netflix 真實影片上驗證**。模擬測試不代表所有 Netflix 帳號、字幕樣式及播放器版本都已相容。
